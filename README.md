Victor Kipyegon's Portfolio

Welcome to my personal developer portfolio. This project showcases my skills and experience as a Full-Stack Web Developer specializing in the MERN stack (MongoDB, Express.js, React.js, and Node.js). The portfolio highlights projects I’ve built, technologies I use, and ways to contact or collaborate with me.

Tech Stack

Frontend: React.js (with Vite), Tailwind CSS, JavaScript (ES6+)

Backend: Node.js, Express.js

Database: MongoDB (with Mongoose)

Version Control: Git, GitHub

API Integration: RESTful APIs, Axios

Deployment: Vercel (Frontend), Render or Heroku (Backend)

Features

Interactive and modern design with smooth animations
Project gallery with live demos and GitHub links
Contact form with working backend or email service
Mobile-responsive and fully accessible
Fast performance optimized with Vite
